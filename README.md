# 🛰️ World Watch — ศูนย์เฝ้าระวังสถานการณ์โลก

เว็บหน้าเดียวที่รวม 3 เรื่องเข้าด้วยกัน

1. **จุดร้อนทางภูมิรัฐศาสตร์** ที่อาจลุกลามเป็นสงครามใหญ่ — จัดกลุ่มตามสมรภูมิ พร้อมลิงก์ต้นทางทุกข่าว
2. **การเคลื่อนไหวผิดปกติ** ของทองคำ น้ำมัน ค่าเงิน และสินทรัพย์อื่นรวม 18 ตัว
3. **แปลว่าอะไรกับประเทศไทย** — ราคาทองบาทละ ค่าไฟ ค่าน้ำมัน และกำลังซื้อของลูกค้าต่างชาติ

**โค้ดทั้งหมดอยู่ในไฟล์เดียวคือ `app.py`** — ไฟล์อื่นในโฟลเดอร์เป็นแค่ไฟล์ตั้งค่าสำหรับเอาขึ้นเว็บ

รันได้ 2 โหมดจากไฟล์เดียวกัน: **เซิร์ฟเวอร์** (`py app.py`) และ **สร้างหน้าเว็บนิ่ง** (`py app.py --build site`)

## ⚡ เริ่มใช้ใน 3 ขั้นตอน

### 1. โหลดโค้ดและติดตั้ง Flask (ทำครั้งเดียว)

```bash
git clone https://github.com/realnonn-stack/World-Watch-III.git
```

หรือกดปุ่มเขียว **Code → Download ZIP** บนหน้า GitHub แล้วแตกไฟล์เอาก็ได้ จากนั้นติดตั้ง Flask

```bash
py -m pip install flask
```

> ใช้ `py` บน Windows · ถ้าเป็น Mac หรือ Linux ให้ใช้ `python3` แทนทุกคำสั่งในคู่มือนี้

### 2. สั่งรัน

เข้าไปที่โฟลเดอร์ที่วางไฟล์ไว้ แล้วสั่งรัน

```bash
cd path\to\World-Watch-III
```

```bash
py app.py
```

หรือถ้าไม่อยาก `cd` จะใส่ path เต็มของไฟล์ไปเลยก็ได้ เช่น `py C:\myfolder\app.py`

### 3. เปิดเบราว์เซอร์

```
http://127.0.0.1:5000
```

> **หน้าแรกจะค้าง 5-15 วินาที** เพราะกำลังดึงข่าว 16 แหล่ง + ราคา 18 ตัวพร้อมกัน
> ครั้งต่อไปเร็วขึ้นเพราะมีแคช 10 นาที

**ปิดเซิร์ฟเวอร์:** กลับไปที่หน้าต่าง PowerShell กด `Ctrl + C`
**ห้ามปิดหน้าต่าง PowerShell ระหว่างใช้งาน** — ปิดเมื่อไหร่เว็บดับทันที

### ลูกเล่นที่ควรรู้

- **ปุ่ม "ดึงข้อมูลใหม่"** (บนขวา) — ข้ามแคช ดึงสดทันที
- **ปุ่ม EN** — สลับป้ายกำกับเป็นอังกฤษ (พาดหัวข่าวคงภาษาต้นทางเสมอ)
- **ช่องใส่ราคาทรัพย์** ในส่วนไทย — ใส่ราคาจริงของดีลที่กำลังคุยอยู่ กด "คำนวณใหม่" จะได้ตัวเลขว่าลูกค้าแต่ละสัญชาติต้องจ่ายเท่าไหร่ในสกุลเงินตัวเอง
- **กล่องที่มีลูกศร ▾** กดเปิดได้ทุกอัน ข้างในคือสูตรและตัวเลขดิบ
- หน้าเว็บ **รีเฟรชเองทุก 10 นาที** เปิดทิ้งไว้บนจอที่สองได้

## 🔢 อ่านตัวเลขยังไง

### z-score — "วันนี้มันวิ่งแรงกว่าปกติกี่เท่า"

```
z = (ผลตอบแทนวันนี้ − ค่าเฉลี่ยผลตอบแทน 90 วัน) ÷ ส่วนเบี่ยงเบนมาตรฐาน 90 วัน
```

เทียบกับนิสัยของสินทรัพย์ตัวนั้นเอง ทำให้เทียบทองกับบิตคอยน์ได้อย่างเป็นธรรม

| ค่า | แปลว่า | เกิดบ่อยแค่ไหน |
|---|---|---|
| `\|z\| < 1.5` | ปกติ | เกือบทุกวัน |
| `\|z\| ≥ 1.5` | เริ่มน่าจับตา | — |
| `\|z\| ≥ 2` | ผิดปกติ | ~5% ของวันทำการ |
| `\|z\| ≥ 3` | ผิดปกติรุนแรง | ~0.3% ของวัน (ปีละครั้งสองครั้ง) |

### ดัชนีความตึงเครียด (เต็ม 100)

| องค์ประกอบ | เต็ม | สูตร |
|---|---|---|
| ข่าวยกระดับความรุนแรง 48 ชม. | 40 | ความรุนแรงของเหตุการณ์ที่แรงที่สุด (0–10) × 2.5 + จำนวนโซนที่มีเหตุระดับ 7 ขึ้นไป × 3 |
| สินทรัพย์เคลื่อนไหวผิดปกติ | 35 | ผลรวมของ (min(\|z\|,4) − 1) × 4 เฉพาะตัวที่ \|z\| ≥ 1.5 |
| รูปแบบหนีเข้าที่หลบภัย | 25 | ทอง +8 · VIX +7 · น้ำมัน +5 · หุ้นสหรัฐฯ +3 · พันธบัตร +2 |

| คะแนน | ระดับ |
|---|---|
| 0-24 | ปกติ |
| 25-44 | เฝ้าระวัง |
| 45-64 | ตึงตัว |
| 65-84 | อันตราย |
| 85-100 | วิกฤต |

> ⚠️ **ดัชนีนี้เครื่องมือนี้คำนวณขึ้นเอง ไม่ใช่ดัชนีมาตรฐานสากล**
> ใช้เพื่อจัดลำดับว่าควรสนใจอะไรก่อน ไม่ใช่การพยากรณ์ว่าจะเกิดสงคราม

### ระดับความรุนแรงของข่าวแต่ละชิ้น (0–10)

ตัวเลขในกล่องซ้ายของแต่ละข่าว มาจากคลังคำ 4 ระดับ

| น้ำหนัก | ความหมาย | ตัวอย่างคำ |
|---|---|---|
| **10** | สัญญาณสงครามใหญ่ของจริง | `nuclear strike` `article 5` `declares war` `general mobilization` `defcon` |
| **7** | ปฏิบัติการทางทหารตรง ๆ | `missile strike` `airstrike` `invasion` `blockade` `strait of hormuz` `martial law` |
| **5** | ตึงเครียดแต่ยังไม่ปะทะเต็มรูปแบบ | `sanctions` `border clash` `drone attack` `ultimatum` `war games` `shot down` |
| **3** | ควรรู้ไว้ ยังไม่ใช่เรื่องด่วน | `troop buildup` `arms deal` `conscription` `nato` `war` |

**ถ้าข่าวเดียวเจอหลายคำ** — คำที่แรงที่สุดได้เต็ม แล้วคำถัดไปบวกทีละ 2 (ไม่บวกกันตรง ๆ ไม่งั้นข่าวยาว ๆ จะพองเกินจริง)

| ตัวปรับ | ผล |
|---|---|
| เจอคำผ่อนคลาย (`ceasefire agreement`, `peace deal`, `truce`) | **−5** |
| พาดหัวเป็นข่าวรำลึก/รณรงค์ (`disarmament`, `survivor`, `memorial`) | **เหลือ 0** |
| มีสำนักข่าวอิสระ 3 แห่งขึ้นไปรายงานเรื่องเดียวกัน | **+1** |
| เพดาน | **10** |

สีในหน้าเว็บ: 🔴 **8–10** รุนแรงมาก · 🟡 **6–7** ปฏิบัติการทหาร · 🔵 **5** ตึงเครียดระดับการทูต

> ระบบนี้**จับคำ ไม่ได้เข้าใจภาษา** ใต้พาดหัวทุกข่าวจึงแสดงไว้ว่าจับคำไหนได้ เพื่อให้ตรวจสอบเองได้ว่าสมเหตุสมผลไหม

### ระดับความน่าเชื่อถือของแหล่งข่าว

| ระดับ | ความหมาย | ตัวอย่าง |
|---|---|---|
| **A** | ตรวจสอบได้ / องค์กรทางการ | BBC World, UN News, IAEA |
| **B** | สื่อหลัก มีบรรณาธิการ แต่มีจุดยืนของประเทศตัวเอง | Reuters, Al Jazeera, DW, France 24, CNBC, SCMP, Bangkok Post |
| **C** | ต้องตรวจสอบต้นทางก่อน | Google News (ตัวรวมข่าว), Investing.com |
| **D** | ระวังสูง — อ่านเอาท่าที ไม่ใช่เอาข้อเท็จจริง | TASS (สื่อรัฐรัสเซีย), Global Times (สื่อรัฐจีน), ZeroHedge |

ข่าวระดับ C/D และข่าวที่ใช้คำกำกวม (`reportedly`, `claims`, `อ้างว่า`) จะถูกดันเข้าส่วน **"น่าสนใจแต่เชื่อไม่ได้"** พร้อมบอกเหตุผลเป็นรายชิ้น

## 🔧 ปรับแต่งได้ตรงไหนบ้าง

แก้ได้ในไฟล์ `app.py` ส่วน **"1. ค่าคงที่ / การตั้งค่า"** (บรรทัดต้นๆ ของไฟล์)

| ตัวแปร | ค่าเริ่มต้น | ใช้ทำอะไร |
|---|---|---|
| `CACHE_TTL_SEC` | `600` | อายุแคช (วินาที) ลดแล้วข้อมูลสดขึ้นแต่ยิงแหล่งข้อมูลถี่ขึ้น |
| `HTTP_TIMEOUT` | `12` | รอแต่ละแหล่งกี่วินาทีก่อนยอมแพ้ |
| `DEFAULT_PROPERTY_THB` | `10_000_000` | ราคาทรัพย์ตั้งต้นในตารางกำลังซื้อ |
| `FEEDS` | 16 แหล่ง | เพิ่ม/ลดแหล่งข่าว — ต้องระบุ `tier` เป็น A/B/C/D ทุกครั้ง |
| `ASSETS` | 18 ตัว | เพิ่ม/ลดสินทรัพย์ ใส่ได้ทั้งสัญลักษณ์ Stooq และ Yahoo |
| `ESCALATION_KEYWORDS` | ~50 คำ | คำที่บ่งชี้การยกระดับความรุนแรง พร้อมน้ำหนัก 3/5/7/10 |
| `DEESCALATION_KEYWORDS` | 11 คำ | คำที่บ่งชี้การผ่อนคลาย เจอแล้วหักคะแนน 5 |
| `HEDGE_WORDS` | 21 คำ | คำกำกวมที่ทำให้ข่าวถูกติดป้าย "ยังไม่ยืนยัน" (มีคำไทยด้วย) |
| `THEATRES` | 7 โซน | สมรภูมิและคำสำคัญของแต่ละโซน |

**อยากเน้นชายแดนไทยมากขึ้น** → เพิ่มคำในโซน `thailand` ของ `THEATRES`
**เปลี่ยนพอร์ต** → แก้ `port=5000` ที่บรรทัดสุดท้ายของไฟล์

## 🛡️ กฎที่โค้ดนี้ยึด

- **ไม่มีตัวเลข hard-code แม้แต่ตัวเดียว** ทุกตัวเลขดึงสดแล้วคำนวณจริง
- **ดึงไม่ได้ = บอกว่าดึงไม่ได้** ขึ้นกล่อง "⚠️ ดึงข้อมูลไม่สำเร็จ — ไม่แสดงตัวเลขเดา" พร้อม error จริง ไม่แต่งข้อมูลมาแทน
- **ทุกสูตรเปิดให้ตรวจย้อนกลับ** กดดูได้ในหน้าเว็บว่าใช้สูตรอะไร ใส่ค่าอะไรเข้าไป
- **ทุกข่าวมีลิงก์ต้นทาง + เวลา + ระดับความน่าเชื่อถือ**
- **แหล่งที่ล้มเหลวก็แสดง** ไม่ซ่อน เพื่อให้รู้ว่าภาพที่เห็นขาดอะไรไป

### ความปลอดภัย

โปรแกรมนี้**ไม่แตะข้อมูลลูกค้า ข้อมูลทรัพย์ หรือค่าคอมใดๆ** ไม่ใช้ `.env` ไม่ใช้ service account
อ่านอย่างเดียวจากแหล่งสาธารณะ — ก๊อปไฟล์ส่งใครก็ได้โดยไม่มีข้อมูลลับหลุด

- **ไม่ใช่คำแนะนำการลงทุน และไม่ใช่การพยากรณ์สงคราม** ก่อนตัดสินใจอะไร ให้กดเข้าไปอ่านต้นทางเสมอ

## 🚀 เอาขึ้นเว็บให้คนอื่นเปิดดูได้

ไฟล์นี้รันได้ 2 โหมด และ repo นี้เตรียมไฟล์ให้ครบทั้งสองทางแล้ว

| | **GitHub Pages** | **Render** |
|---|---|---|
| ค่าใช้จ่าย | ฟรีถาวร ไม่จำกัด (repo public) | ฟรี ไม่ต้องผูกบัตร |
| คนกดลิงก์แล้ว | ขึ้นทันที | หลับหลังไม่มีคนใช้ 15 นาที คนแรกรอ ~1 นาที |
| ความสดของข้อมูล | เท่ารอบ cron ล่าสุด (ทุก 30 นาที) | สดตอนกด |
| ปุ่ม "ดึงข้อมูลใหม่" | ไม่มี (ไม่มีเซิร์ฟเวอร์) | ใช้ได้ |
| เหมาะกับ | **ส่งลิงก์ให้คนอื่นดู** | ใช้เองตอนอยากได้ข้อมูลสดเดี๋ยวนั้น |

ทั้งสองทางใช้โค้ดคำนวณและหน้าตาชุดเดียวกันหมด และ**เครื่องคำนวณกำลังซื้อลูกค้าต่างชาติใช้ได้ทั้งคู่** เพราะคำนวณฝั่งเบราว์เซอร์

---

### ทางที่ 1 — GitHub Pages (แนะนำสำหรับส่งลิงก์)

ไฟล์ [`.github/workflows/site.yml`](.github/workflows/site.yml) เตรียมไว้ให้แล้ว เหลือเปิดสวิตช์ครั้งเดียว

1. ไปที่ **Settings → Pages**
2. ช่อง **Source** เลือก **GitHub Actions**
3. ไปที่แท็บ **Actions → build-site → Run workflow** เพื่อสั่งรันรอบแรกเลย (ไม่ต้องรอ cron)

เสร็จแล้วจะได้ลิงก์หน้าตา `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` และ GitHub จะสร้างหน้าใหม่ให้เองทุก 30 นาที

**ทดสอบในเครื่องก่อนได้** — สร้างไฟล์นิ่งออกมาดูเองว่าหน้าตาตรงกับที่จะขึ้นจริงไหม

```bash
py app.py --build site
```

ได้ `site/index.html` + `site/snapshot.json` มาเปิดดูได้เลย

> ⚠️ **สองเรื่องที่ต้องรู้**
> - ถ้าดึงข้อมูลไม่ได้เลยสักแหล่ง สคริปต์จะจบด้วยสถานะล้มเหลว **ไม่เผยแพร่ทับของเดิม** หน้าเว็บเก่ายังอยู่ ดีกว่าขึ้นหน้าเปล่าให้คนอื่นเห็น
> - GitHub จะ**ปิด cron อัตโนมัติถ้า repo ไม่มี commit ใหม่เลย 60 วัน** (มีอีเมลเตือนก่อน) ถ้าโดนปิดให้กด Enable workflow ในแท็บ Actions หรือ push อะไรสักอย่างขึ้นไปก็นับใหม่

---

### ทางที่ 2 — Render (เซิร์ฟเวอร์จริง กดดึงข้อมูลสดได้)

ไฟล์ [`render.yaml`](render.yaml) เตรียมไว้ให้แล้ว

1. สมัคร [render.com](https://render.com) (ไม่ต้องใส่บัตร) แล้วเชื่อมบัญชี GitHub
2. **New → Blueprint** → เลือก repo นี้ → **Apply**

ถ้าอยากตั้งเองด้วยมือ ให้เลือก **New → Web Service** แล้วกรอกแค่ 2 ช่อง

| ช่อง | ใส่ |
|---|---|
| Build Command | `pip install -r requirements.txt` |
| Start Command | `gunicorn app:app --bind 0.0.0.0:$PORT --workers 1 --threads 8 --timeout 120` |

> `--workers 1` สำคัญ — ถ้าหลาย worker แต่ละตัวจะแยกแคชกันเอง แล้วยิงแหล่งข้อมูลซ้ำซ้อนโดยไม่จำเป็น

---

### เปิดจากมือถือในวง WiFi เดียวกัน

ไม่ต้องแก้โค้ดแล้ว สั่งผ่าน environment variable ได้เลย

```bash
$env:HOST="0.0.0.0"; py app.py
```

แล้วเข้าจาก `http://<IP ของเครื่อง>:5000`

⚠️ ทุกคนที่ต่อ WiFi เดียวกันเปิดดูได้หมด ไม่มีรหัสผ่าน
