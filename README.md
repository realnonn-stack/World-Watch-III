# 🛰️ World Watch — ศูนย์เฝ้าระวังสถานการณ์โลก

เว็บหน้าเดียวที่รวม 3 เรื่องเข้าด้วยกัน

1. **จุดร้อนทางภูมิรัฐศาสตร์** ที่อาจลุกลามเป็นสงครามใหญ่ — จัดกลุ่มตามสมรภูมิ พร้อมลิงก์ต้นทางทุกข่าว
2. **การเคลื่อนไหวผิดปกติ** ของทองคำ น้ำมัน ค่าเงิน และสินทรัพย์อื่นรวม 18 ตัว
3. **แปลว่าอะไรกับประเทศไทย** — ราคาทองบาทละ ค่าไฟ ค่าน้ำมัน และกำลังซื้อของลูกค้าต่างชาติ

ทั้งโปรเจคอยู่ในไฟล์เดียวคือ `app.py`

---

## ⚡ เริ่มใช้ใน 3 ขั้นตอน

### 1. ติดตั้ง Flask (ทำครั้งเดียว)

```bash
py -m pip install flask
```

### 2. สั่งรัน

```bash
py D:\Realcado\website\app.py
```

รันจากที่ไหนก็ได้ ไม่ต้อง `cd` เข้าโฟลเดอร์ก่อน

### 3. เปิดเบราว์เซอร์

```
http://127.0.0.1:5000
```

> **หน้าแรกจะค้าง 5-15 วินาที** เพราะกำลังดึงข่าว 16 แหล่ง + ราคา 18 ตัวพร้อมกัน
> ครั้งต่อไปเร็วขึ้นเพราะมีแคช 10 นาที

**ปิดเซิร์ฟเวอร์:** กลับไปที่หน้าต่าง PowerShell กด `Ctrl + C`
**ห้ามปิดหน้าต่าง PowerShell ระหว่างใช้งาน** — ปิดเมื่อไหร่เว็บดับทันที

### ลูกเล่นที่ควรรู้

- **ปุ่ม "ดึงข้อมูลใหม่"** (บนขวา) — ข้ามแคช ดึงสดทันที
- **ปุ่ม EN** — สลับป้ายกำกับเป็นอังกฤษ (พาดหัวข่าวคงภาษาต้นทางเสมอ)
- **ช่องใส่ราคาทรัพย์** ในส่วนไทย — ใส่ราคาจริงของดีลที่กำลังคุยอยู่ กด "คำนวณใหม่" จะได้ตัวเลขว่าลูกค้าแต่ละสัญชาติต้องจ่ายเท่าไหร่ในสกุลเงินตัวเอง
- **กล่องที่มีลูกศร ▾** กดเปิดได้ทุกอัน ข้างในคือสูตรและตัวเลขดิบ
- หน้าเว็บ **รีเฟรชเองทุก 10 นาที** เปิดทิ้งไว้บนจอที่สองได้

## 🔢 อ่านตัวเลขยังไง

### z-score — "วันนี้มันวิ่งแรงกว่าปกติกี่เท่า"

```
z = (ผลตอบแทนวันนี้ − ค่าเฉลี่ยผลตอบแทน 90 วัน) ÷ ส่วนเบี่ยงเบนมาตรฐาน 90 วัน
```

เทียบกับนิสัยของสินทรัพย์ตัวนั้นเอง ทำให้เทียบทองกับบิตคอยน์ได้อย่างเป็นธรรม

| ค่า | แปลว่า | เกิดบ่อยแค่ไหน |
|---|---|---|
| `\|z\| < 1.5` | ปกติ | เกือบทุกวัน |
| `\|z\| ≥ 1.5` | เริ่มน่าจับตา | — |
| `\|z\| ≥ 2` | ผิดปกติ | ~5% ของวันทำการ |
| `\|z\| ≥ 3` | ผิดปกติรุนแรง | ~0.3% ของวัน (ปีละครั้งสองครั้ง) |

### ดัชนีความตึงเครียด (เต็ม 100)

| องค์ประกอบ | เต็ม | สูตร |
|---|---|---|
| ข่าวยกระดับความรุนแรง 48 ชม. | 40 | ผลรวมน้ำหนักคำสำคัญของข่าวระดับ A/B × 0.7 |
| สินทรัพย์เคลื่อนไหวผิดปกติ | 35 | ผลรวมของ (min(\|z\|,4) − 1) × 4 เฉพาะตัวที่ \|z\| ≥ 1.5 |
| รูปแบบหนีเข้าที่หลบภัย | 25 | ทอง +8 · VIX +7 · น้ำมัน +5 · หุ้นสหรัฐฯ +3 · พันธบัตร +2 |

| คะแนน | ระดับ |
|---|---|
| 0-24 | ปกติ |
| 25-44 | เฝ้าระวัง |
| 45-64 | ตึงตัว |
| 65-84 | อันตราย |
| 85-100 | วิกฤต |

> ⚠️ **ดัชนีนี้เครื่องมือนี้คำนวณขึ้นเอง ไม่ใช่ดัชนีมาตรฐานสากล**
> ใช้เพื่อจัดลำดับว่าควรสนใจอะไรก่อน ไม่ใช่การพยากรณ์ว่าจะเกิดสงคราม

### ระดับความน่าเชื่อถือของแหล่งข่าว

| ระดับ | ความหมาย | ตัวอย่าง |
|---|---|---|
| **A** | ตรวจสอบได้ / องค์กรทางการ | BBC World, UN News, IAEA |
| **B** | สื่อหลัก มีบรรณาธิการ แต่มีจุดยืนของประเทศตัวเอง | Reuters, Al Jazeera, DW, France 24, CNBC, SCMP, Bangkok Post |
| **C** | ต้องตรวจสอบต้นทางก่อน | Google News (ตัวรวมข่าว), Investing.com |
| **D** | ระวังสูง — อ่านเอาท่าที ไม่ใช่เอาข้อเท็จจริง | TASS (สื่อรัฐรัสเซีย), Global Times (สื่อรัฐจีน), ZeroHedge |

ข่าวระดับ C/D และข่าวที่ใช้คำกำกวม (`reportedly`, `claims`, `อ้างว่า`) จะถูกดันเข้าส่วน **"น่าสนใจแต่เชื่อไม่ได้"** พร้อมบอกเหตุผลเป็นรายชิ้น

## 🔧 ปรับแต่งได้ตรงไหนบ้าง

แก้ได้ในไฟล์ `app.py` ส่วน **"1. ค่าคงที่ / การตั้งค่า"** (บรรทัดต้นๆ ของไฟล์)

| ตัวแปร | ค่าเริ่มต้น | ใช้ทำอะไร |
|---|---|---|
| `CACHE_TTL_SEC` | `600` | อายุแคช (วินาที) ลดแล้วข้อมูลสดขึ้นแต่ยิงแหล่งข้อมูลถี่ขึ้น |
| `HTTP_TIMEOUT` | `12` | รอแต่ละแหล่งกี่วินาทีก่อนยอมแพ้ |
| `DEFAULT_PROPERTY_THB` | `10_000_000` | ราคาทรัพย์ตั้งต้นในตารางกำลังซื้อ |
| `FEEDS` | 16 แหล่ง | เพิ่ม/ลดแหล่งข่าว — ต้องระบุ `tier` เป็น A/B/C/D ทุกครั้ง |
| `ASSETS` | 18 ตัว | เพิ่ม/ลดสินทรัพย์ ใส่ได้ทั้งสัญลักษณ์ Stooq และ Yahoo |
| `ESCALATION_KEYWORDS` | ~50 คำ | คำที่บ่งชี้การยกระดับความรุนแรง พร้อมน้ำหนัก 3/5/7/10 |
| `DEESCALATION_KEYWORDS` | 11 คำ | คำที่บ่งชี้การผ่อนคลาย เจอแล้วหักคะแนน 5 |
| `HEDGE_WORDS` | 21 คำ | คำกำกวมที่ทำให้ข่าวถูกติดป้าย "ยังไม่ยืนยัน" (มีคำไทยด้วย) |
| `THEATRES` | 7 โซน | สมรภูมิและคำสำคัญของแต่ละโซน |

**อยากเน้นชายแดนไทยมากขึ้น** → เพิ่มคำในโซน `thailand` ของ `THEATRES`

## 🛡️ กฎที่โค้ดนี้ยึด

- **ไม่มีตัวเลข hard-code แม้แต่ตัวเดียว** ทุกตัวเลขดึงสดแล้วคำนวณจริง
- **ดึงไม่ได้ = บอกว่าดึงไม่ได้** ขึ้นกล่อง "⚠️ ดึงข้อมูลไม่สำเร็จ — ไม่แสดงตัวเลขเดา" พร้อม error จริง ไม่แต่งข้อมูลมาแทน
- **ทุกสูตรเปิดให้ตรวจย้อนกลับ** กดดูได้ในหน้าเว็บว่าใช้สูตรอะไร ใส่ค่าอะไรเข้าไป
- **ทุกข่าวมีลิงก์ต้นทาง + เวลา + ระดับความน่าเชื่อถือ**
- **แหล่งที่ล้มเหลวก็แสดง** ไม่ซ่อน เพื่อให้รู้ว่าภาพที่เห็นขาดอะไรไป

### ความปลอดภัย

โปรแกรมนี้**ไม่แตะข้อมูลลูกค้า ข้อมูลทรัพย์ หรือค่าคอมใดๆ** ไม่ใช้ `.env` ไม่ใช้ service account
อ่านอย่างเดียวจากแหล่งสาธารณะ — ก๊อปไฟล์ส่งใครก็ได้โดยไม่มีข้อมูลลับหลุด

## ❗ ข้อจำกัดที่ต้องรู้ก่อนใช้

- **ราคาเป็นราคาปิดรายวัน ไม่ใช่เรียลไทม์** — ใช้ดูแนวโน้ม ไม่ใช้เทรด
- **อ่านข่าวด้วยการจับคำสำคัญ ไม่ได้เข้าใจบริบทเหมือนคน** — มีทั้งเตือนเกินจริงและพลาดข่าวสำคัญได้
- **"ไม่มีข่าว" ไม่ได้แปลว่า "ไม่มีอะไรเกิดขึ้น"** แปลแค่ว่า 16 แหล่งที่ตั้งไว้ยังไม่รายงาน
- **ดัชนีความตึงเครียดเป็นการให้คะแนนของเครื่องมือนี้เอง** ไม่ใช่มาตรฐานที่ใครยอมรับ
- **ไม่ใช่คำแนะนำการลงทุน และไม่ใช่การพยากรณ์สงคราม** ก่อนตัดสินใจอะไร ให้กดเข้าไปอ่านต้นทางเสมอ

## 🚀 ถ้าจะเอาขึ้นใช้จริงจัง

**เปิดจากมือถือใน WiFi เดียวกัน** — แก้บรรทัดสุดท้ายเป็น `host="0.0.0.0"` แล้วเข้าจาก IP ของเครื่อง
⚠️ แปลว่าทุกคนที่ต่อ WiFi เดียวกันเปิดดูได้หมด ควรใส่รหัสผ่านก่อน

**เอาขึ้นอินเทอร์เน็ตจริง** — **ห้ามใช้ dev server ของ Flask** ต้องเปลี่ยนไปใช้ `waitress` (Windows) หรือ `gunicorn` (Linux)

```bash
py -m pip install waitress
```

คำสั่งนี้ต้อง `cd` เข้าโฟลเดอร์ก่อน เพราะ waitress ต้อง import `app.py` จากที่ที่ยืนอยู่

```bash
cd D:\Realcado\website
```

```bash
py -m waitress --host=0.0.0.0 --port=8080 app:app
```

(ตัวติดตั้งจะเตือนว่า `waitress-serve.exe` ไม่อยู่ใน PATH — ไม่ต้องสนใจ เพราะเราเรียกผ่าน `py -m waitress` แทนอยู่แล้ว)

**ต่อกับ LINE ให้แจ้งเตือนอัตโนมัติ** — ใช้ `/api/snapshot` ที่คืน JSON อยู่แล้ว
ตั้ง cron ยิงมาเช็ก ถ้า `tension.score` เกินเกณฑ์ค่อยส่งเข้า LINE Messaging API
